🚀 Acabei de colocar no ar mais um projeto solo: o **Onde Assistir a Copa 2026**.

Um app web rápido e mobile-first pra acompanhar toda a Copa do Mundo 2026 — horários, estádios, canais de TV/streaming, tabela dos 12 grupos, chaveamento de mata-mata interativo e placar atualizado em tempo real.

🔗 **Acesse:** https://onde-assistir-copa-2026.vercel.app/

💻 **Código no GitHub:** https://github.com/alexsantos-djesus/onde-assistir-copa-2026

🧱 **Stack & ferramentas:**
• Front: React 19 + TypeScript + Vite 7
• Framework: TanStack Start v1 (SSR + Server Functions)
• Estado: TanStack Query v5
• Estilos: Tailwind CSS v4 + shadcn/ui
• Banco: Supabase (PostgreSQL + RLS + Auth)
• API: TheSportsDB (sync automático de placares)
• Deploy: Vercel
• PM: Bun

✨ **O que dá pra fazer no app:**
→ Agenda completa com filtros combináveis (data, status, fase, busca textual) com queries reativas via TanStack Query
→ Painel admin protegido para editar placar e status em tempo real
→ Tabela de grupos com critérios FIFA
→ Mata-mata interativo com chaveamento visual
→ Placar ao vivo com sync automático

Projeto pequeno, mas feito com carinho pra acompanhar a Copa em casa com a galera. 🇧🇷⚽

👉 **Entra no site, testa, e me conta o que achou nos comentários!** Feedback sobre UX, performance ou qualquer ideia de feature é super bem-vindo — quero evoluir ele até a estreia da Copa.
